## WHAT CHANGED IN v2.0

1. **Gate 0 added ahead of the Algorithm** — impossibility classification, floor computation, failure-value check, three-failure test.
2. **The four types of impossibility** (Physical / Capability / Cost / Permission) — because his documented failures are all *classification* errors, not effort errors.
3. **The calibration rule** — his own stated rule is a 50% deadline; his measured record is ~91% late. Any announced schedule gets a 1.5–3× slip factor.
4. **Two new self-checks** — "Is the goal too small?" and "Did I classify the impossibility before attacking it?"
5. **Source tiers made binding** — T4 sources (X, Reddit, model memory) are never citations.
6. **The cost side made mandatory in the summary** — a protocol that hides the ~91% lateness, the firings, and the credit dependency is propaganda.
